Use this template to create your own curling game reporting website to share with your friends and family! Just populate the games csv with your games using the format (I left a couple examples to make it easy to follow) and host it somewhere. I recommend hosting using github pages, it is very simple you can find the setup instructions here: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

You can see my example populated site at https://meganbanaski.github.io/CurlingGames/
